# 회원가입 동의 안내창

## 변경 내용

개인정보 수집·이용(필수), AI 생성 콘텐츠 안내(필수), 학습 알림 메일 수신(선택)의 세 안내창.
제목 또는 아직 체크되지 않은 체크박스를 누르면 안내창을 열고, 안내창 동의 버튼을 눌러야 체크한다.
체크된 항목은 체크박스로 해제 가능하다. 재열람 후 닫기/Esc는 동의 상태를 변경하지 않는다.
필수 두 항목으로만 가입 버튼을 활성화하며 선택 항목은 기본 미동의다.
API 요청 필드명 agreePrivacy / agreeAiNotice / agreeMarketing은 유지했다.
백엔드·DB·메일 발송·Google OAuth는 이 변경에 포함되지 않는다.
브라우저 native dialog를 사용하여 배경 접근과 키보드 초점을 제한하고, 닫을 때 원래 위치로 초점을 되돌린다.
모바일에서 본문은 스크롤되며 창 하단에 동의 버튼이 있다.

## 안내 문구의 근거와 확인이 필요한 항목

현재 공유된 회원가입 API, 학습 기능 설명과 기존에 정한 탈퇴 프로필 1년 보관 기준으로 만든 검토용 문구다.
법률 적합성이 검증된 개인정보처리방침 전체를 대체하는 문서는 아니다.
기존 화면의 '모든 일정은 AI 생성', '캘린더 정보를 현재 수집'처럼 구현 범위를 넘어갈 수 있는 단정은 수정했다.

공개 배포 전 팀에서 확인할 항목:
- 실제 서비스 운영주체와 연락처, 열람·정정·삭제·처리정지·동의철회 요청 방법을 개인정보처리방침에 명시.
- migration 010의 실제 보관 항목·목적·기간과 문구 일치 확인. 1년은 법정 보관 기간이라고 단정하지 않음.
- Supabase·Vercel·Codyssey 게이트웨이·AI 처리 제공자의 실제 역할, 처리위탁·제3자 제공·국외이전 적용 여부와 필요한 고지/절차 확인.
- 가입 후 학습 메일 수신 동의 철회 경로와 발송 시 동의 확인 로직 점검. 이 변경은 그 기능을 새로 구현하지 않음.
- 현재 agreeMarketing 필드는 UI에서 '학습 알림 메일 수신'으로 표시된다. 실제 광고 수신으로 확대하려면 내용과 동의 범위를 먼저 정리.
- 현재 API에는 동의 여부와 동의 시각을 저장한다. 안내문 버전별 증빙이 필요하면 별도 정책·스키마 작업으로 진행.
- 각 항목의 법적 근거/필수 범위 및 미성년자 가입 정책은 운영 범위에 맞춰 검토.

안내 항목 검토 참고: 개인정보 보호법 제15조(수집·이용), 제30조(처리방침).
https://www.law.go.kr/법령/개인정보보호법

## 검증 (프로젝트 루트 PowerShell)

```powershell
npm --prefix frontend run lint
npm --prefix frontend run build
git diff --check
git status --short
```

실제 회원가입 요청을 보내지 않고 아래 동작부터 확인한다.
1. 세 항목 모두 미동의, 가입 버튼 비활성.
2. 제목/체크박스로 세 안내창 각각 열기. Esc/닫기는 체크하지 않음.
3. 개인정보 동의만 하면 가입 버튼 비활성. AI 동의도 하면 활성.
4. 선택 항목이 미동의여도 가입 가능. 선택 동의/해제가 필수 항목을 바꾸지 않음.
5. 필수 동의를 해제하면 가입 버튼 다시 비활성.
6. 안내창을 다시 열고 닫아도 기존 동의 유지. 이메일/닉네임 입력값도 유지.
7. Tab 초점이 안내창 내부에 머무르고 닫으면 연 버튼/체크박스로 복귀.
8. 모바일 폭에서 가로 넘침 없이 본문 스크롤/하단 버튼 이용.

현재 안내 내용을 프론트 화면에만 반영한다. 공용 DB 변경, 커밋, 푸시는 자동 실행하지 않는다.
