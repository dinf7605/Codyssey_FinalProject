# 참여자 안내 (보내는 글 모음)

> 단톡·DM 에 그대로 붙여 쓸 수 있게 나눠 두었다. `[ ]` 안만 바꿔서 보낸다.

---

## 1. 모집 글

```
[5일 사용 테스트 참여자 모집] 자격증·공모전 준비하시는 분!

코디세이 최종 프로젝트로 만든 'StudyPace' 를 5일 동안 써 주실 분을 찾습니다.
목표(예: SQLD, 토익, 공모전)를 넣으면 AI가 단원으로 나누고,
내 빈 시간에 맞춰 '오늘 무엇을 공부할지' 일정을 짜 주는 서비스예요. 밀리면 밤사이 다시 짜 줍니다.

- 기간: [10/6(화) ~ 10/10(토)] · 하루 5분이면 충분 (실제 공부는 원래 하시던 만큼)
- 대상: 지금 자격증이나 공모전을 준비 중인 분
- 하는 일: 첫날 가입 + 계획 만들기(10분) → 매일 일정 확인·완료 체크 → 끝나고 설문 5분 + 짧은 인터뷰 15분
- 무료 · 비영리 학습 프로젝트 · 끝나면 원하실 때 계정과 기록을 모두 지울 수 있어요

참여 가능하시면 [연락처/폼 링크] 로 알려 주세요
```

---

## 2. 시작 안내 (첫날)

```
참여해 주셔서 감사합니다! 오늘 10분만 내 주세요.

1) 접속: https://codyssey-final-project.vercel.app
   (PC 크롬 권장 · 휴대폰도 됩니다)

2) 가입: '회원가입' → 이메일로 가입하거나 '구글 계정으로 계속하기'
   - 구글 로그인은 [미리 알려 주신 Gmail] 로만 됩니다
   - 동의 항목 중 '학습 알림 수신(선택)'은 [그룹 B 는 체크 / 그룹 A 는 자유]

3) 목표 만들기: '내게 맞는 목표 찾기'
   - 관심 분야 → 공부 가능한 시간(요일·시간대) → 추천 목표 중 고르기
   - 원하는 목표가 없으면 '목표를 직접 입력할게요'
   - 추천 카드마다 '관심 있음 / 관심 없음'을 눌러 주세요 (평가로 씁니다)

4) 계획 만들기: AI가 단원으로 나누는 데 30~60초 걸려요. 결과를 보고 '확정'
   - 구글 캘린더를 쓰신다면 '구글 캘린더에서 바쁜 시간 가져오기'로 일정 피해서 놓기
     (일정 제목은 읽지 않고 바쁜 시간대만 한 번 읽어요.
      '확인되지 않은 앱' 화면이 나오면 '고급 → 이동'을 누르시면 됩니다)

5) 알림 설정: 마이페이지 → 알림 설정 → 알림 강도 [그룹 A: 보통 / 그룹 B: 강 + '학습 독촉' 켜기] → 저장
   - 알림은 사이트 안(오른쪽 위 알림)에 쌓이고, '브라우저 알림도 받기'를 허용하면
     사이트를 열어 둔 동안 브라우저 알림도 떠요. 이메일·문자로는 오지 않아요

6) 매일: 공부할 때 블록의 '시작' → 끝나면 '완료'. 못 한 날은 그냥 두셔도 밤사이 다시 놓아 드려요
```

## 3. 참여 동의 (첫날 받기)

```
[StudyPace 사용 테스트 참여 동의]

1. 목적: 서비스 개선과 코디세이 최종 프로젝트 결과 보고
2. 수집 항목
   - 서비스 이용 기록: 목표·계획·학습 기록·알림 기록·추천 평가 (서비스 개인정보 처리방침과 같음)
   - 설문 응답, 인터뷰 내용
3. 이용 방법: 결과 보고서와 발표에는 'P1, P2 …' 처럼 이름 없이 숫자로만 씁니다.
   이메일·이름은 보고서에 넣지 않습니다
4. 보관과 삭제
   - 테스트 명단(이름·연락처)은 프로젝트 종료(10/20) 후 삭제합니다
   - 서비스 계정은 원하시면 언제든 마이페이지 '회원 탈퇴'로 지울 수 있습니다
     (탈퇴하면 일정·학습 기록·알림은 바로 삭제, 프로필은 서비스 정책대로 1년 보관 후 삭제)
5. 인터뷰 녹음: 별도로 여쭤보고, 동의하신 경우에만 녹음하며 정리 후 바로 삭제합니다
6. 참여는 자유이며 언제든 그만두실 수 있습니다

□ 위 내용을 읽고 테스트 참여에 동의합니다
□ (선택) 인터뷰 녹음에 동의합니다
```

## 4. 매일 저녁 한 줄 질문 (22시)

| 날 | 질문 |
|---|---|
| 1일차 | 오늘 만든 첫 일정, 바로 해 볼 만해 보였나요? 걸리는 게 있었다면 한 가지만! |
| 2일차 | 오늘 일정 중 하나라도 해 보셨나요? 완료 체크까지 하셨나요? |
| 3일차 | 아침에 '밤사이 일정이 바뀌었다'는 알림을 보셨다면, 바뀐 일정이 납득되셨나요? |
| 4일차 | 알림이 도움이 됐나요, 귀찮았나요? |
| 5일차 | 내일부터도 계속 쓸 것 같나요? 이유 한 줄! |

> 답이 없어도 재촉하지 않는다. 이틀 연속 기록이 없으면 "막힌 게 있으셨는지"만 개별로 묻는다.

## 5. 자주 묻는 것

| 질문 | 답 |
|---|---|
| 일정이 안 맞아요 | 일정 화면에서 블록을 다른 날로 끌어 놓거나(PC) 블록 메뉴 '⋯ → 옮기기'. 직접 옮긴 블록은 자동 재조정에서 빠져요 |
| 못 한 블록은요? | 새벽 3시에 남은 기간으로 다시 놓아요. 아침 알림으로 무엇이 바뀌었는지 알려 드려요 |
| 공부 시간을 바꾸고 싶어요 | 마이페이지 → 목표 관리 → '공부 시간 바꾸기' |
| 알림이 안 와요 | 사이트 안 알림을 먼저 확인. 브라우저 알림은 사이트를 열어 둔 동안만 떠요 |
| 목표를 바꾸고 싶어요 | 마이페이지 → 목표 관리 → '목표 종료' 후 새 목표 찾기 (동시에 2개까지) |
| 기록을 지우고 싶어요 | 마이페이지 → '저장된 학습 정보' 항목별 삭제, 또는 '회원 탈퇴' |
