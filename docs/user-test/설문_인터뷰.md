# 설문 · 인터뷰 문항

> 사후 설문은 구글 폼으로 옮겨 쓴다 (5분). 문항 번호는 리포트 표와 맞춘다.
> 사후 인터뷰 1~5 는 기획서 8-2절 정성 질문 그대로다.

---

## 1. 사전 인터뷰 (첫날, 10분)

1. 지금 무엇을 준비하고 있나요? 언제까지인가요?
2. 지금은 공부 계획을 어떻게 세우나요? (플래너, 앱, 머릿속 …)
3. 계획이 밀리거나 무너졌던 경험이 있나요? 그때 어떻게 했나요?
4. 한 주에 공부할 수 있는 시간은 대략 얼마인가요?
5. 이 서비스에 기대하는 것 한 가지는?

> 4번 답과 온보딩에서 실제로 고른 시간을 비교하면 '가용시간 입력이 현실적이었나'를 볼 수 있다.

---

## 2. 사후 설문 (구글 폼, 5분)

**척도: 1 전혀 아니다 · 2 아니다 · 3 보통 · 4 그렇다 · 5 매우 그렇다**

### A. 핵심 기능

| 번호 | 문항 | 연결 |
|---|---|---|
| A1 | 추천된 목표가 내 관심·상황에 맞았다 | 목표 추천 (P1) |
| A2 | 처음 만들어진 일정을 보고 **바로 실행할 수 있겠다**고 느꼈다 | 학습 분해·배치 (P3) |
| A3 | 단원 나누기(학습 단위와 시간)가 실제 시험·공모전 준비 내용과 맞았다 | 학습 분해 Agent |
| A4 | 일정이 밀렸을 때 **밤사이 다시 놓인 일정을 믿고 따를 수 있었다** | 야간 재조정 (P4) |
| A5 | 지금 잘 가고 있는지(진도 신호등·주간 요약)를 알 수 있었다 | 진도 (P5) |
| A6 | 추천 이유를 읽고 왜 추천됐는지 납득했다 | AI 추천 이유 |
| A7 | 'AI가 만든 내용은 부정확할 수 있다'는 안내를 봤고, 결과를 확인하고 썼다 | AI 윤리 고지 |

### B. 알림 (그룹 A 보통 / B 강)

| 번호 | 문항 |
|---|---|
| B0 | 내 알림 강도: ○ 보통 ○ 강 ○ 기억 안 남 |
| B1 | 알림이 공부를 시작하는 데 도움이 됐다 (1~5) |
| B2 | 알림이 부담스럽거나 귀찮았다 (1~5) |
| B3 | 알림 때문에 서비스를 덜 열게 된 적이 있다 ○ 예 ○ 아니오 |
| B4 | 알림을 어떻게 받고 싶나요? (복수) □ 사이트 안 □ 브라우저 알림 □ 이메일 □ 카톡·문자 □ 받기 싫다 |

### C. 사용성 (SUS, 10문항 · 1~5)

1. 이 서비스를 자주 쓰고 싶다
2. 쓸데없이 복잡하다고 느꼈다
3. 쓰기 쉬웠다
4. 쓰려면 다른 사람의 도움이 필요할 것 같다
5. 여러 기능이 잘 어우러져 있다
6. 앞뒤가 맞지 않는 부분이 많았다
7. 대부분의 사람이 금방 익힐 것 같다
8. 쓰기 번거로웠다
9. 쓰면서 자신감이 있었다
10. 쓰기 전에 배워야 할 것이 많았다

> 점수 계산: 홀수 문항은 (응답 − 1), 짝수 문항은 (5 − 응답)을 더해 × 2.5 → 0~100. **68점이 평균**.

### D. 계속 사용

| 번호 | 문항 |
|---|---|
| D1 | 테스트가 끝나도 계속 쓸 생각이 있다 (1~5) |
| D2 | 비슷한 준비를 하는 친구에게 추천할 가능성 (0~10) |

### E. 서술 (선택)

- E1. 가장 좋았던 것 한 가지
- E2. 가장 불편했거나 이해가 안 됐던 것 한 가지
- E3. 있었으면 하는 기능

## 3. 사후 인터뷰 (15분)

설문 응답을 먼저 보고, 점수가 극단적인 문항부터 묻는다.

1. 생성된 첫 일정을 보고 **바로 실행 가능하다고 느꼈나요**? 아니라면 무엇이 걸렸나요?
   - 보조: 블록 길이·시간대·단원 순서 중 무엇이 안 맞았나
2. 일정이 밀렸을 때 **야간 재조정 결과를 신뢰**했나요?
   - 보조: 아침 알림을 봤나 · 바뀐 걸 직접 다시 옮긴 적이 있나 (있다면 왜)
3. 알림 강도는 **도움이 되었나요, 부담이었나요**? (FR-ALARM-02 독촉 강도 검증)
   - 보조: 어떤 알림이 제일 쓸모 있었나 · 끄고 싶었던 알림
4. 추천 이유를 읽고 **왜 추천됐는지 납득**했나요?
   - 보조: 사실과 다른 말이 있었나
5. 이 서비스를 계속 쓸 의향이 있나요? 없다면 이유는?
6. (사전 인터뷰 3번과 비교) 예전처럼 계획이 무너진 순간이 있었나요? 그때 서비스가 한 일이 도움이 됐나요?

> 녹음은 동의한 참여자만. 정리 뒤 바로 지운다. 리포트에는 P번호와 요지만 쓴다.
