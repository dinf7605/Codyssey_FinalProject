## 2. 기능 상세

### FR-AUTH-01 회원가입 · 로그인

| 항목 | 내용 |
|---|---|
| 기능 | 정보 입력과 필수 동의 후 가입 · 인증 메일 확인 후 이메일과 비밀번호로 로그인 |
| 세부 기능 | 비밀번호 8~64자, 영문 · 숫자 · 특수문자 각 1자 이상 / 닉네임 2~10자 / 입력 중 비밀번호 조건 충족 여부를 실시간 표시 / 필수 동의 2개 — 개인정보 수집 동의, AI 이용 고지 (AI 가 만든 추천 · 일정은 부정확할 수 있음) |
| 필요한 데이터 | 이메일, 비밀번호 (Supabase Auth 해시), 닉네임, 동의 여부 · 동의 일시 |
| 세부 사항 | 필수 동의를 모두 체크해야 가입 버튼 활성화 / 가입 후 '인증 메일을 보냈어요' 안내와 다시 보내기 / 인증 전 로그인은 인증이 필요하다고 안내 / 로그인 실패 문구는 계정 존재 여부와 관계없이 동일 / 5회 연속 실패 시 60초 잠금 |
| 통합한 ID | FR-AUTH-01 · FR-JOIN-01 · FR-JOIN-02 · FR-JOIN-03 |
| 관련 | NFR-SEC-01 · NFR-SEC-03 · NFR-PRIV-01 · NFR-ETHIC-01 |

### FR-GOAL-01 관심분야 · 가용 시간 입력

| 항목 | 내용 |
|---|---|
| 기능 | 관심 태그를 고르거나 직접 입력한 뒤, 요일별 공부 가능 시간대를 고른다 |
| 세부 기능 | 관심 태그 최대 5개 / 직접 입력 100자 / 입력 없이 건너뛰기 가능 / 요일 × 시간대 선택 |
| 필요한 데이터 | 관심 태그, 직접 입력 텍스트, 요일, 시작 · 종료 시각 |
| 세부 사항 | 관심분야 입력 없이 건너뛰면 인기 목표를 바탕으로 비슷한 분야를 추천 |
| 통합한 ID | FR-GOAL-01 · FR-GOAL-02 |

### FR-GOAL-05 목표 추천 카드

| 항목 | 내용 |
|---|---|
| 기능 | Claude (Haiku) 가 목표 카탈로그에서 관심분야와 관련된 자격증 · 공모전 후보를 고르고, 가용 시간으로 기간 적합성을 계산해 카드로 보여 준다 |
| 세부 기능 | 관련성 0.60 이상인 후보만 사용 / 추천 3~5개 (적합 후보가 3개 미만이면 있는 만큼) / 카드마다 목표명 · 준비 약 N주 · 추천 이유 · 'AI 추천' 배지 / 최소 기간 = 표준 학습시간 ÷ 주간 가용시간, 권장 기간 = 최소 기간 × 1.3 |
| 필요한 데이터 | 관심 태그, 목표 카탈로그 (표준 학습시간 · 시험일 · 마감일), 주간 가용시간, 관련성 점수, 추천 이유 |
| 세부 사항 | 시험일 · 마감일 안에 끝낼 수 없는 후보는 제외하고, 권장 기간보다 빠듯하면 '빠듯해요' 표시 / AI 응답 실패 (시간 초과 · 키 없음 · 검증 실패) 시 태그 겹침 검색으로 대체 / AI 생성물은 부정확할 수 있다는 고지를 상시 표시 |
| 통합한 ID | FR-GOAL-03 · FR-GOAL-04 · FR-GOAL-05 · FR-GOAL-09 |
| 관련 | AI기능명세 ③ · NFR-ETHIC-01 |

### FR-STUDY-01 학습 타이머 · 블록 완료

| 항목 | 내용 |
