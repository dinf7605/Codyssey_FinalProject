> 10개에 묶이지 않은 원래 Must 20개는 Should 로 내렸다. 기능은 그대로 남아 있고 동작한다 ([아래 표](#should-로-내린-기능)).

## Must 상세 — 합격 기준

합격 기준의 항목이 모두 되면 그 Must 는 통과다.

### 1. FR-AUTH-01 회원가입 · 로그인

이메일 · 비밀번호 · 닉네임으로 가입하고, 메일 인증 뒤 로그인한다.

- 비밀번호 조건(8~64자, 영문 · 숫자 · 특수문자 각 1자 이상)을 입력하는 동안 충족 여부로 보여 준다.
- **개인정보 수집 동의**와 **AI 이용 고지**(추천 목표와 일정은 AI 가 만들며 부정확할 수 있음)를 모두 체크해야 가입 버튼이 눌린다.
- 가입하면 "인증 메일을 보냈다"는 안내가 나온다. 메일의 링크로 인증한 뒤 로그인할 수 있다.
- 로그인에 실패하면 없는 이메일과 틀린 비밀번호에 같은 문구를 보여 준다.

근거: `routers/auth.py` · `app/signup/page.js` · `components/SignupConsentFields.js` · `tests/test_auth_signup.py` · `test_login_lock_contest_fix.py`

### 2. FR-GOAL-01 관심분야 · 주간 가용 시간 입력

목표 추천에 쓸 관심분야와 공부할 수 있는 시간을 입력한다.

- 1단계: 관심분야를 칩으로 고르거나 직접 입력한다. 입력 없이 **건너뛰기**도 할 수 있다.
- 2단계: 요일별로 공부할 수 있는 시간대를 고른다.

근거: `app/onboarding/page.js` · `lib/planInput.js` · `GET /goal/tags`

### 3. FR-GOAL-05 AI 목표 추천 카드

입력한 관심분야와 가용 시간에 맞는 자격증 · 공모전 목표를 카드로 추천받는다.

- 추천 카드를 최대 5개 보여 준다. 카드마다 **추천 이유**와 **준비 약 N주**(예상 기간)가 있다.
- AI(Claude)가 고른 카드에는 **'AI 추천'** 표시와 부정확할 수 있다는 안내가 붙는다.
- 주간 가용 시간으로 시험일 · 마감일 안에 끝낼 수 없는 목표는 빠지고, 빠듯한 목표에는 '빠듯해요'가 붙는다.
- AI 응답이 늦거나 실패해도 규칙 기반 추천으로 카드가 나온다.

근거: `services/goal_claude.py` · `goal_recommender.py` · `goal_feasibility.py` · `tests/test_goal_router.py` · `test_goal_feasibility.py` · 정답셋 측정 ([RESULTS](../backend/evals/RESULTS.md))

### 4. FR-GOAL-07 목표 확정

추천 카드(또는 직접 입력한 목표) 하나를 확정해 일정 만들기로 넘어간다.

- 확정하면 `/schedule` 의 계획 만들기로 이어진다.
- 진행 중인 목표는 최대 2개다. 이미 2개면 하나를 먼저 끝내라고 안내한다.

근거: `routers/goal.py` (`MAX_ACTIVE_GOALS = 2`) · `components/PlanBuilder.js` · `tests/test_multiplan.py`

### 5. FR-PLAN-02 AI 학습 분해

AI 에이전트가 목표를 학습 단원으로 나누고 단원별 시간을 정한다.

- 계획 만들기를 누르면 진행 단계를 보여 주며 분해한다 (보통 30초 안팎).
- 결과는 단원 이름과 예상 시간(분) 목록이다.
- AI 결과가 검증을 통과하지 못하면 1회 다시 시도하고, 그래도 안 되면 기본 커리큘럼으로 만든다 ('기본 계획' 표시).

근거: `services/decomposer.py` · `agent_tools.py` · `POST /plan/decompose/stream` · `tests/test_decomposer.py` · `test_agent_tools.py`

### 6. FR-PLAN-03 빈 시간에 자동 배치

나눈 단원을 2단계에서 고른 빈 시간에 자동으로 놓는다.

- 블록 하나는 최대 120분이다. 더 긴 단원은 블록 여러 개로 나눠 순서대로 놓고 제목에 (1/3) 처럼 순서를 붙인다.
- 하루 최대 3블록, 주 1일은 휴식일로 비운다.
- 기한 안에 자리가 없는 단원은 '미배치'로 따로 보여 준다.

근거: `services/scheduler.py` · `validator.py` · `schemas/plan.py` · `tests/test_scheduler.py` · `test_validator.py`

### 7. FR-PLAN-04 주 · 월 일정 조회

저장한 계획을 달력으로 본다.

- **주 / 월** 버튼으로 보기를 바꾼다.
- 블록마다 날짜 · 시간 · 단원이 보이고, 미배치 단원은 목표별로 따로 모아 보여 준다.

근거: `components/PlanCalendar.js` · `GET /plan/active` · `tests/test_unplaced_notes.py`

### 8. FR-MAIN-03 오늘의 학습 블록

대시보드에서 오늘 할 블록을 확인한다.

- 오늘 놓인 블록을 시간 순서대로 보여 준다.
- 오늘 블록이 없으면 이유를 알려 준다 (휴식일 / 공부 시간으로 고르지 않은 요일).

근거: `app/(app)/dashboard/page.js` · `components/DayTimeline.js`

### 9. FR-STUDY-01 학습 타이머 · 블록 완료

블록을 골라 타이머로 공부하고 완료한다.

- **시작 · 일시정지 · 이어서 · 완료** 버튼이 있다.
- 5분 미만이면 완료 버튼이 눌리지 않는다 (기록하지 않음).
- 완료하면 공부 시간이 기록되고 블록이 완료로 표시된다. 방금 한 완료는 24시간 안에 **완료 취소**할 수 있다.

근거: `components/StudyTimer.js` · `routers/study.py` · `POST /study/sessions` · `tests/test_plan_store.py` · `test_replan.py`

### 10. FR-STUDY-03 학습 즉시 집계

완료한 학습이 바로 통계에 반영된다.

- 완료 직후 누적 학습 시간 · 이번 주 학습 시간 · 연속 학습일 · 이번 주 블록 완료율이 새 값으로 바뀐다.

근거: `services/aggregator.py` · `GET /study/stats` · `tests/test_aggregator.py`

## 확인 순서 (약 10분)

1. `/signup` 에서 가입 → 인증 메일의 링크 → `/login` 로그인 (1)
2. `/onboarding` 에서 관심분야 고르기 → 요일 · 시간대 고르기 (2)
3. 추천 카드에서 이유 · 준비 기간 · 'AI 추천' 표시 확인 → 하나 확정 (3 · 4)
4. `/schedule` 에서 계획 만들기 → 단원 목록 확인 → 미리보기에서 배치 확인 → 저장 (5 · 6)
5. 달력에서 주 / 월 바꿔 보기 (7)
6. `/dashboard` 에서 오늘 블록 확인 (8)
7. `/study` 에서 블록 시작 → 5분 뒤 완료 → 통계가 바뀌는지 확인 → 완료 취소 (9 · 10)

오늘이 휴식일이거나 공부 시간으로 고르지 않은 요일이면 6단계는 안내 문구만 나온다. 2단계에서 오늘 요일을 고르면 오늘 블록이 생긴다.
