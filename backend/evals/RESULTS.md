## 읽는 법 · 사람이 채점할 항목

- **목표 추천 적합도**: 같은 정답셋 20개를 태그 겹침(09-29 이전 방식)과 Claude 관련성(지금)으로 잰다. 3차(10-01) 태그 40% → Claude 100% — 글자가 안 겹치는 관심사(예: "회사 서류 작업을 빨리 하고 싶어요" → 컴활)를 Claude 만 찾는다. 무관 관심사 2개(요리·피아노)는 둘 다 추천 없음으로 통과
- **공모전 Precision@5**: 기획서 정의대로 "추천 공고가 접수 중이고 마감 전인가"만 자동으로 잰다. 응모 자격은 원문을 읽지 않아 판정하지 않는다. **관심사와 실제로 맞는지(관련성)는 사람이 본다** — results/*.json 의 titles 를 팀원 2명이 적합/부적합으로 교차 채점
- **추천 이유 사실성**: 이유 문장이 말한 근거(제목·분야에 키워드 포함, 입력한 관심 태그)가 실제와 맞는 비율
- 아직 자동으로 못 재는 것: 학습 분해 누락률(표준 커리큘럼 대비, 목표 10% 이하) · 일정 준수율 · 재조정 안정성 · 중간 목표 적정성 — 실사용자 5명 테스트(4차) 때 DB 기록으로 잰다
